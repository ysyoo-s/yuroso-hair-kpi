# YUROSO HAIR (유로소 헤어) 통합 KPI & 고객관리(CRM) 경영 시스템 (웹 · 모바일 앱)

네이버 플레이스 유로소 헤어 감성의 **웜 아이보리(`#FAF7F2`) · 에스프레소 브라운(`#2C221E`) · 샴페인 골드(`#B08968`) · 세이지 올리브(`#6B7F6E`)** 컬러 시스템을 적용한 3대 지점(**파주 운정점 · 운정역점 · 마곡발산점**) 통합 KPI 및 고객관리(CRM) 웹 & 모바일 앱(PWA) 애플리케이션입니다.

## 주요 기능 요약
1. **핸드폰 어플(App) 다운로드 & 설치 지원 (Android / iPhone / iPad PWA)**:
   - 상단 **[📲 핸드폰 앱 다운로드]** 버튼 및 하단 플로팅 앱 설치 배너를 통해 원클릭 앱 설치(`beforeinstallprompt`) 및 기기별(갤럭시·아이폰) 맞춤 설치 가이드를 제공합니다.
   - 전용 고해상도 아이콘(`180x180`, `192x192`, `512x512`, `maskable`)과 서비스워커([`sw.js`](file:///home/antigravity/ysyoo-s/yuroso-hair-kpi/sw.js))가 탑재되어 주소창 없는 네이티브 전체화면(`standalone`) 어플로 실행됩니다.
2. **로그인 필수 게이트 & 임직원 인증**:
   - 대표원장 · 관리자 직통 접속 및 지점원장 · 디자이너 회원가입/로그인과 **기기 자동 로그인 유지(`localStorage`)**를 지원합니다.
3. **직급별 엄격한 열람 권한 분리 (RBAC)**:
   - **대표원장 (영화 대표원장)**: 전 지점 매출 성장(30%) / 영업이익(30%) / 지점 목표 달성(20%) / 리더·인재 성장(20%) KPI 평가 및 3개 지점 모든 원장·디자이너의 일·월·년 비교 그래프 통합 조회
   - **지점원장 (파주 운정점·운정역점·마곡발산점 원장)**: 본인 소속 지점 데이터만 열람 가능, 지점 매출(35%) / 디자이너 평균매출 성장(30%) / 재방문 고객 비율(20%) / 직원 성장·유지(15%) KPI 및 소속 디자이너 비교 그래프 조회
   - **디자이너**: 본인의 개인 KPI 대시보드와 CRM 입력 내역만 열람
4. **디자이너용 CRM 5대 지표 자동계산기**:
   - ① 개인매출, ② 총 고객수, ③ 신규 고객수, ④ 재방문 고객수, ⑤ 객단가 5개 항목 입력 시 **재방문 고객 비율(재방문 고객수 ÷ 총 고객수)** 및 **디자이너 KPI 점수(개인매출 40% / 재방문 비율 30% / 객단가 20% / 신규 고객수 10%)** 실시간 자동 산출 및 대시보드 즉시 반영
5. **3대 지점 지점원장 & 총 결과 KPI 달성 현황 비교 분석 대시보드**

## 핸드폰 어플 설치 방법
- **갤럭시 / 안드로이드 (Chrome · 삼성 인터넷)**:
  1. 사이트 접속 후 상단 또는 하단 배너의 **[📲 앱 다운로드]** 버튼 클릭 → **[설치]** 확인
  2. (카카오톡 내부에서 열렸다면 **[🌐 Chrome 브라우저로 바로 열기]** 클릭 후 설치)
- **아이폰 / 아이패드 (Safari)**:
  1. Safari로 접속 후 하단 중앙 **[공유 📤]** 버튼 터치
  2. **[홈 화면에 추가 ➕]** 선택 후 우측 상단 **[추가]** 터치
