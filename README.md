# YUROSO HAIR (유로소 헤어) 통합 KPI & 고객관리(CRM) 경영 시스템

네이버 플레이스 유로소 헤어 감성의 **웜 아이보리(`#FAF7F2`) · 에스프레소 브라운(`#2C221E`) · 샴페인 골드(`#B08968`) · 세이지 올리브(`#6B7F6E`)** 컬러 시스템을 적용한 3대 지점(**파주 운정점 · 운정역점 · 마곡발산점**) 통합 KPI 및 고객관리(CRM) 웹 애플리케이션입니다.

## 주요 기능 요약
1. **로그인 필수 게이트 & 카카오톡 계정 접속**: 비로그인 시 대시보드 열람을 차단하며, 카카오톡 간편 로그인 및 신규 회원가입(이름 / 3대 지점 선택 / 3대 직급 선택)과 **기기 자동 로그인 유지(`localStorage`)**를 지원합니다.
2. **직급별 엄격한 열람 권한 분리 (RBAC) & 상단 권한 전환 바**:
   - **대표원장 (영화 대표원장)**: 전 지점 매출 성장(30%) / 영업이익(30%) / 지점 목표 달성(20%) / 리더·인재 성장(20%) KPI 평가 및 3개 지점 모든 원장·디자이너의 일·월·년 비교 그래프 통합 조회
   - **지점원장 (파주 운정점·운정역점·마곡발산점 원장)**: 본인 소속 지점 데이터만 열람 가능, 지점 매출(35%) / 디자이너 평균매출 성장(30%) / 재방문 고객 비율(20%) / 직원 성장·유지(15%) KPI 및 소속 디자이너 비교 그래프 조회
   - **디자이너**: 본인의 개인 KPI 대시보드와 CRM 입력 내역만 열람
3. **디자이너용 CRM 5대 지표 자동계산기**:
   - ① 개인매출, ② 총 고객수, ③ 신규 고객수, ④ 재방문 고객수, ⑤ 객단가 5개 항목 입력 시 **재방문 고객 비율(재방문 고객수 ÷ 총 고객수)** 및 **디자이너 KPI 점수(개인매출 40% / 재방문 비율 30% / 객단가 20% / 신규 고객수 10%)** 실시간 자동 산출 및 대시보드 즉시 반영
4. **3대 지점 지점원장 & 총 결과 KPI 달성 현황 비교 분석 대시보드**

## GitHub 연동 및 Vercel 배포 방법
1. 본 폴더(`index.html`, `vercel.json`, `package.json`, `README.md`)를 GitHub 리포지토리에 그대로 Push합니다.
2. [Vercel](https://vercel.com)에서 **Add New Project** → 해당 GitHub 리포지토리를 Import합니다.
3. 별도 빌드 설정 없이 **Deploy**를 클릭하면 즉시 배포가 완료됩니다.
