GITHUB + VERCEL + KAKAO OAUTH DEPLOYMENT

GitHub 연동 Vercel 실서버 배포 및 카카오 OAuth 설정

✅ Vercel 무설정(Zero-Config) 정적 배포 완벽 호환

이 웹 애플리케이션은 외부 빌드 의존성 없이 단일 index.html과 vercel.json만으로 GitHub 리포지토리 푸시 즉시 Vercel에서 100% 구동되도록 설계되었습니다.

1단계: GitHub 리포지토리 업로드 및 Vercel 연동

  1. 함께 제공된 배포 패키지(yuroso_hair_vercel_deploy.zip)의 파일들을 GitHub 새 리포지토리에 업로드(Push)합니다.
  2. Vercel Dashboard → Add New Project에서 해당 GitHub 리포지토리를 Import합니다.
  3. Framework Preset은 Other (Static) 그대로 두고 Deploy를 클릭하면 10초 내로 배포가 완료됩니다.

2단계: 실제 Kakao Developers JavaScript 키 연동 (선택 사항)

실제 카카오톡 OAuth 팝업 연동을 원하시면 Kakao Developers에서 앱 생성 후 [플랫폼 → Web]에 Vercel 도메인을 등록하고 아래에 JavaScript 키를 입력하세요. (미입력 시에도 내장 카카오 간편 인증 모달로 모든 기능 사용 가능)

3단계: vercel.json 설정 파일 (SPA 라우팅 & 캐시 최적화)

{
  "version": 2,
  "cleanUrls": true,
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
